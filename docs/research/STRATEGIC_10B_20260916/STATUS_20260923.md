[`PASS_ENGINE_Q4K_Q8K_REFERENCE_GENERIC_COMPILE_PARITY`](../donor_adaptation/probes/STRAT_01_GIGACHAT31_ENGINE_Q4K_Q8K_REFERENCE_GENERIC_COMPILE_PARITY_RESULT_20260923.md).

## Strategic consequence and remaining gates

The immediate engine-fidelity question moves from the Q4 projection operator
to downstream propagation. The next admissible experiment must be separately
frozen and reuse immutable reference checkpoints to determine whether exact
Q4 compiler arithmetic closes the known block-0 terminal and Rung-2C
residuals. Repeating AVX2 parity, model-free Q4 tests, Q/KV projection parity,
or the prior gate/up split would duplicate closed evidence.

That successor is now frozen in the
[reference-generic propagation protocol](../donor_adaptation/probes/STRAT_01_GIGACHAT31_ENGINE_REFERENCE_GENERIC_PROPAGATION_PROTOCOL_20260923.md).
It reuses immutable Rung-2C reference checkpoints, keeps every prior numerical
gate, permits one C producer invocation for both schedules, and forbids any
reference graph execution. Its result will decide whether to expand to the
next layer or localize the earliest remaining dependency; it cannot establish
quality or rate.

Its [apparatus qualification](../donor_adaptation/probes/STRAT_01_GIGACHAT31_ENGINE_REFERENCE_GENERIC_PROPAGATION_APPARATUS_RESULT_20260923.md)
now passes: immutable references validate, 131 Python tests and all C
self-tests are green, source controls are live, and zero graphs ran. The one
scientific C-producer invocation remains unmeasured and is the next step.

That invocation is now closed as a valid
[`FAIL_ENGINE_REFERENCE_GENERIC_PROPAGATION`](../donor_adaptation/probes/STRAT_01_GIGACHAT31_ENGINE_REFERENCE_GENERIC_PROPAGATION_RESULT_20260923.md).
