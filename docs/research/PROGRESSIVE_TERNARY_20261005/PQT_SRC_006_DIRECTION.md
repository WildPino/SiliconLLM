Prospective direction after SRC005 qualification, 6 October 2026. This is not
an experiment admission or a completed result. Keep the full research goal

actual original expert contexts; they do not establish their fidelity or quality.

The next useful scientific question is whether the poor original FFN transfer
observed in PQT005-R1 persists on independently bound inputs from the original
float encoder-decoder model, with broader observed expert coverage. Inherited

The current qualified operator accepts pre-extracted checked NPY tensors.
Original Switch has29,859,401,788 archive bytes and7,415,217,408 unique F32
parameters. Blindly duplicating all tensors into NPY would impose substantial
scratch and transport costs. SRC003's selected118 MiB operation did not measure
those complete-source costs. Before model capture, implement and qualify a
separate source provider that reads the admitted ZIP tensors directly into
bounded buffers, verifies each tensor identity before use, counts every load,
and releases expert pairs. Keep the already qualified numerical operator
unchanged; use the same load(name, device) contract. A counted, bounded scratch
cache is an alternative only after its actual worst-case bytes and eviction
rules are frozen. Neither strategy is currently implemented or admitted.

Separate provider controls from pretrained function execution. Freeze its
namespace, full contiguous F32 storage/alias requirements, maximum tensor/read/
resident-buffer sizes, complete I/O and deadline stops before testing. Verify
positive tensor values against the qualified extraction and independent Torch
fixtures; reject corrupted bytes, unexpected pickle globals, changed archives,
nonfinite payloads, aliases/layout mismatch, partial reads and incomplete pair
cleanup. Retain all first failures and complete source closure. A successful
provider qualification alone does not admit natural context capture.

Then preregister one bounded original float capture: exact source revision,
tokenizer/corpus identities and licenses, frozen nonoverlapping document splits,
seed and masked-span corruption, encoder and teacher-forced decoder conditioning,
original capacity64 and deterministic F32/no-cache SDPA. Define observed versus
dispatched expert rows, capacity drops, padding/discard rules, minimum useful
calibration/development/held-out coverage and stop-on-insufficient-coverage.
Keep naturally rare experts rare; forced routing is a labeled diagnostic.
Bind independent original-weight FFN/F64 references and a feasible complete-model
reference strategy before claiming float-context fidelity. Count all original
checkpoint acquisition/transfer/read/cache costs and actual allocator/RSS peaks.

Only after qualification select a materially new output-guided discrete method
from the evidence. Freeze matched baselines, update/data budgets, local/transfer/
whole-model gates and full scales/correction storage before fitting. Do not
repeat identical failed fits or relax preservation criteria after results.
Every long T4 dispatch requires fresh account/resource admission and delegated
status-only monitoring while the coordinator waits dormant. Native CPU timing
remains a separate pending owner reservation.
