# Conditional precision: a possible variable, with historical boundaries

15 October 2026. Proposal only; no converter, quality or cost admission.

Mixed-precision residual corrections are not new to this repository. [METH238](../NATIVE_EXPERT_SCALING_20260925/METH_238_OUTLIER_SPLIT_NATIVE_RESULT_20261001.md) implemented a Q8 base plus indexed BF16 exceptions. [METH240](../NATIVE_EXPERT_SCALING_20260925/METH_240_MIXED_CONDITIONAL_PAIR_RESULT_20261001.md) and [METH244](../NATIVE_EXPERT_SCALING_20260925/METH_244_READOUT_ENCODING_RESULT_20261001.md) show that favorable operator fidelity or continuous fits need not survive conditional quality and physical encoding. [METH246](../NATIVE_EXPERT_SCALING_20260925/METH_246_SINGLE_TEAM_RESIDUAL_RESULT_20261001.md) reduced native residual cost, but [METH247](../NATIVE_EXPERT_SCALING_20260925/METH_247_WEIGHTED_RESIDUAL_PAIR_RESULT_20261001.md) still failed the paired quality comparison. The earlier [shared-base residual bank](../NATIVE_EXPERT_SCALING_20260925/METH_155_MATCHED_SHARED_BASE_RESIDUAL_TRAINING_RESULT_20260928.md) also did not establish a fresh-quality gain in [METH156](../NATIVE_EXPERT_SCALING_20260925/METH_156_FACTORIZED_E12800_FRESH_PREDICTION_RESULT_20260928.md). Do not rebrand any of these timings as a new pipeline result.

A distinguishable future test would retain each original donor expert's coefficients as a low-bit same-expert base plus a higher-precision correction, then allocate a strict per-token correction-byte allowance among the already selected experts. This preserves original expert identity and provides full-refinement/unrefined controls; it differs from inventing an output-space bank or counting duplicated experts. It is a hypothesis for retaining pretrained information while consulting expensive precision selectively, rather than deleting that information from the only stored representation.

The correction selector, amplitudes, metadata, gather cost and cold payload must all be charged. If every selected expert receives its complete correction every token, this is source execution in another encoding and solves no active-cost problem. If omitted corrections cause quality failure, the fact that their coefficients remain in RAM does not preserve useful capability. The preflight's roughly555MB mixed-format row leaves little weight margin; a correction policy must identify where its added bytes come from. No correction selector, own-history quality control, measured kernel or useful-n result currently qualifies this branch. It is not the automatic next experiment after source capture.
