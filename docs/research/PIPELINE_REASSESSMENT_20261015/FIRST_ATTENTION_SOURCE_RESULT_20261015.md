# Actual first-attention source slice: acquisition closed

15 October 2026. **Acquisition and offline custody audit PASS.** This supplies
actual first-block values for a local compression experiment; it establishes
no function preservation, chatbot quality, CPU speed or useful large capacity.

The pinned GPT-OSS-120B slice contains ten BF16 tensors (53,106,048 bytes) and
1,501 used embedding rows (8,645,760 bytes). No experts, complete embedding,
vocabulary head or full checkpoint was acquired. The 36 public-message cases
retain 24 FIT cases from eight sources and 12 DEV cases from four disjoint
sources, with distinct group and first-user keys. Canonical token IDs are
retained; each evaluated prefix is capped at 256 tokens. The shared 62-token
prefix is excluded from the local function gates.

Acquisition freeze `bbb4a24` completed with exit 0 in 892.36 seconds; the
manifest's pre-terminal time is 892.11 seconds. OS peak was 827,441,152 bytes,
and the complete source directory occupies 93,685,386 bytes. All 1,023 recorded
HTTP requests succeeded with exact 206 ranges: 70,662,528 weight-body bytes and
9,992 header-body bytes. The previously verified 27,889,210 tokenizer bytes
were reused with zero new tokenizer network bytes. These are acquisition byte
counts, not inference DRAM traffic.

The separate standard-library CPU audit, frozen at `d638fab`, exited 0 in
2.641 seconds. It replayed public-case selection, all retained file/input
seals and ID hashes, exact range accounting, all complete-tensor response
hashes, and 780 embedding responses reconstructed entirely from retained rows.
The other 205 embedding responses include 8,910,720 unused gap bytes that were
not retained; their complete response hashes cannot be independently replayed.
Raw shard headers were also not retained: their recorded hashes and original
keyset/contiguity checks remain producer witnesses. No remote authenticity or
tokenizer execution proof is inferred from this offline audit.

Three earlier preparation faults remain intact: runtime junction containment,
an invalid tokenizer/physical-vocabulary equality, and the template API's
dictionary default. All stopped before source-weight requests. The final
attempt explicitly validates runtime aliases, vocabulary padding and the list
return type; it reuses the same pinned tokenizer bytes. No case, gate or source
revision was changed in response to numerical outcomes.

The next experiment uses the frozen [rank-256 protocol](FIRST_ATTENTION_RANK_PROTOCOL_20261015.md)
and [binding](first_attention_rank_binding_20261015.json). Its full-rank F32
precision control must pass before Q/O fitting. A local PASS would still need
physical factor kernels, internal-layer and whole-model quality tests, complete
CPU cost, useful conditional capacity and conversion economics.
