## Affine conditional factors and the residual decomposition

For each fixed leaf j, compute weighted FIT means mu_Z,j and mu_Y,j. From
weighted centered Y choose leading output eigenvectors U_j/r. Define real
reference B_j=U_j.T O and b_j=mu_Y,j-U_j B_j mu_Z,j. Execute from INPUT:

    Y_hat = b_j + U_j B_j Z,          j=tree(sparse_projection(Z)).

If Y=OZ exactly, this equals mu_Y,j+U_j U_j.T(Y-mu_Y,j), the optimal local
output-space projection for the fixed partition/rank. Stored Y uses original
