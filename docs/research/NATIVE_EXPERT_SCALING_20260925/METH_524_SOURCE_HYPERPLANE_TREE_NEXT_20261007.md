## Why this variable serves large useful n

523's I16 codec and physical arithmetic add only a few parts per million, but
omitted sign changes give2.682699% unweighted/4.932822% weighted consumed RMS.
Increase region information rather than bits. A source WI hyperplane tests the
exact ideal ReLU sign: WIcode[j] dot q>0, since both source scales are positive.
Use a hard binary tree of these source tests and compile source-fold/hinge
functions in its leaves. A tested path neuron has a KNOWN sign throughout that
leaf, so its continuous source contribution can be folded without sign error.
This is stronger information than proximity to a sample-only cosine centroid.

has one L plus512 explicit hinges. A binary tree supports at most2^d leaves.
RAM grows with stored leaf functions; active route work grows with depth, not

measurement. No meaningful large-n result follows from this deduction alone.
