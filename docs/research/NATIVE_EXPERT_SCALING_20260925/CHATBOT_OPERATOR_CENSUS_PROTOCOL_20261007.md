## Accounting semantics and correctness gates

1. Require exact index/name agreement, shapes/dtypes/contiguous payload ranges
   and length conservation. Bind EVERY tensor to an explicit family operation;
   unknown/missing names or shapes reject. Retained aggregate elements/bytes
   provide a separate conservation witness, not a new model quality reference.
2. Separate stored named elements/bytes, active coefficient budget, matrix MAC
   terms and dynamic attention context terms. Named elements include correction
   buffers/indices/copies; no numeric distinctness/intelligence inference.
   K/E allocations per expert descriptor are bookkeeping of a bank total, NOT
   an assumption of uniform visits or per-name access upper bounds. Actual topK
   banks give exactly K full expert matrices per token. Alias repeats and LUT
   footprint in the existing archive have explicit upper budgets.
3. Source Qwen: bias-free gate/up/down SiLU MLP; biased Q/K/V, bias-free O,
   GQA and RMSNorm/RoPE; tied full vocabulary head. Embedding row is an extra
   logical read of an already bound head field, not extra stored parameters.
4. Source Giga: direct or low-rank Q according to config; KV latent projection,
   latent norm, expanded KV projection and O. Dense first layer, shared SwiGLU
   plus K routed SwiGLU banks afterward. Score every E router row; sigmoid plus
   correction determines choices. Group top2/group topK/selected topK work is
   explicit but exact comparison counts depend on backend. Normalize ORIGINAL
   selected sigmoid weights using selected sum+1e-20 and routed scale, never
   silently replace this with full E softmax.
5. MTP: exact additional layer projection/norm/embedding/head/shared/routed
   tensor binding and stored count, zero main-generation active budget. This
   exclusion applies to plain main decoding; MTP speculation requires its own
   proposal/acceptance/cost qualification. No identity of copied weights implied.
6. Source cache layout follows bound actual local code. Qwen stores GQA K/V

   `Cache.update`; latent MLA cache is only an UNIMPLEMENTED backend alternative.

## Transformation decision after these counts

An exact SwiGLU channel is d_j*SiLU(g_j*x)*(u_j*x). Splitting channels without
redundancy discards a response; copying channels increases stored capacity but
does not remove the need to reconstruct omitted responses. SiLU(z)-z=SiLU(-z)
permits a quadratic gate/up core plus a smooth residual, not the previous ReLU
linear fold. Price a proposed shared low-rank/piecewise/overlapping representation
against the whole head/attention/cache floor before any new source-value fit.
Learning or residual coverage must be declared, never inferred from dimensions.
