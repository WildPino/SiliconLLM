# METH-166: native CPU cost of the 138-tuple shared-context lookup

**Question and decision.** METH-162 fixes one hot route in-sample by growing the structural table from 75 to 138 sorted causal tuples. METH-164 finds no new-source/length load regression. METH-160 already measured actual learned E12,800 BF16 B access with the old table, but the extra lookup cost remains unmeasured. Compare exact old/new table lookup plus the same actual-state parent/child/content route in native C. A pass leaves the table eligible for matched training if METH-165 support also passes; a fail requires a cheaper lookup representation. This is a CPU routing component gate, not a compact LUT, DRAM/cold-cache result or end-to-end accepted-token rate.

Use the exact METH-126 router/A bank and 256×24 METH-125 hidden states from METH-151/160, pinned by their existing SHA-256. Build the new 138-entry binary table directly from METH-162's SHA-256 `dca94f6ea833be5446b497132595ff5dc80d94a414f18a8a2bad116764fac4e1`, preserving sorted `(token,previous,position)` triplets and M151 binary header. Keep the original 75-entry binary table and 256-context old-hit and miss fixtures. Add a third 256-context fixture cycling through all 63 new table entries. Verify Python/C shared classification and grandchild golden outputs on each fixture, including a tuple that changes from content to shared; source-child and four choices must stay identical across table variants.

On one Windows CPU thread, warm the mapped/read inputs, then alternate old/new table order across five paired repetitions per fixture. Time actual-state parent+child+grandchild routing only, including the table lookup once per token and the nine-way content hash when applicable. Report medians, per-repetition times, 75→138 ratios, table bytes, RSS, page faults and output checksums. Freeze pass gates before timing: new-table median <=3.5 ms/token and <=1.25× the old-table median in each of the three fixtures, exact parity and no resource stop. Do not overlap this timing with the METH-165 GPU teacher or route run, so CPU contention cannot obscure a small lookup difference. Stop after 5 minutes or 4 GiB RSS. No T4.
