# METH-113–114: child-residual calibration with a no-child ablation

METH-112 rejects the full-strength METH-107 E1280 checkpoint on arm-blind semantics. Test whether reducing the child-specific residual protects the parent behavior while keeping a genuinely useful 10× larger choice set. This is a new, frozen development intervention; METH-110 excerpts and responses must not be used to select a scale.

For each METH-107 child B factor, define `B(alpha) = B_E128_parent + alpha * (B_METH107_child - B_E128_parent)` with alpha in the fixed set {0.25, 0.5, 0.75, 1.0}. At alpha zero the model has the E128 parent residual, even though it computes child routes; alpha zero is a parity control. Alpha 1.0 is the already rejected METH-107 checkpoint and serves only as a negative control; neither control is eligible for selection. Parent routes, child routes, A factors, BF16 dense donor and four active parent slots remain fixed. No new training or expert removal occurs. The fixed-strength checkpoint METH-107 remains rejected by METH-112 regardless of development observations here.

METH-113 freezes eight code, eight prose and eight general technical new development documents before any alpha scoring. Exclude all prior source IDs and overlapping text fragments through METH-110. Use untouched disjoint 1-MiB windows from positions 128–255 of the pinned Europarl English concatenation as prose candidates. These are byte windows of one corpus, not independent articles. Source, text, token, checkpoint and selection hashes must bind the run.

METH-114 evaluates intact BF16 donor, E128, and each alpha on identical document and prompt IDs, with 128-token greedy generation for E128 and eligible alphas. Require at least 640 sibling-distinct child slots per layer with maximum B-coordinate difference >0.001 **after scaling**. Require E1280−E128 pooled BPB ≤+0.01, each category ≤+0.02, pooled donor prompt top-1 difference ≥−0.01, each category ≥−0.02, and EOS count ≥E128−2. Apply those gates independently to each alpha; do not interpolate or expand the grid after seeing results.

For every automatically passing eligible alpha, compare its selected child B factors against a matched no-child ablation that replaces all ten child B factors of each parent with their mean at that alpha while preserving the same parent and child routing and four active slots. Require selected-child pooled BPB at least 0.00005 lower than the no-child ablation to show a positive use of child choice rather than merely perturbing the parent average. Apply an arm-blind excerpt-only semantic review to new development continuations and require no increase in unsupported claims, severe claims or answers lacking a supported specific detail against E128. Freeze each review verdict before unblinding. Evaluate eligible alphas in descending order (0.75, 0.5, 0.25) and stop at the first passing alpha; this is the largest passing grid point. If none passes, stop. This development criterion is a screening result, not a semantic promotion. Any selected alpha requires a new independent external automatic and arm-blind semantic audit, then learned-factor CPU/LUT and full-model inference measurements. RTX 3060 only; ≤10.5 GiB allocated GPU, ≤20 GiB RSS, ≤15 minutes per evaluation execution. No T4.
