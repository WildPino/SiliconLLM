## Data, algebra and decision

Consume fully audited actual27 model with canonical fixed H/norm substituted
as in the causal bridge, and the qualified alpha.00192-master snapshot from
the grouped-step result. Source and target raw hashes/shape are already known.
Read model coordinates only; no old Adam restoration or numerical proposal.
All92 tensors/721008128 F32 words (~2.884GB raw) encoded, not a sampled subset.

Let source and target F32 words be interpreted as raw32-bit integers a,b.
Store a XOR b losslessly when zlib level1 is smaller than target raw bytes;
otherwise store target raw bytes. Identical chunks store no payload. No float
operation occurs in encoding/decoding, including signed zero or NaN payloads.
Source XOR (source XOR target)=target is exact Boolean algebra.

Chunk4MiB maximum. Record full tensor/source/target and every source/target/
encoded chunk SHA256, shape/dtype, exact offsets/lengths, encoding and changed
word counts. Encoded payload cannot exceed raw target bytes; manifest overhead
is additional and included in output caps. Do not assume good compression on
future gradients/updated models or treat this archive as useful-n capacity.

PASS only if full independent decoder reconstructs EVERY target byte, all
prior source/target hashes match, all chunks cover exactly the parameter extents
and one contiguous payload with no gaps/extra tail, and all input/output hashes
before/after match. Compression ratio is a measurement, not an admission gate.
Independent audit uses Python arbitrary-precision integer byte XOR, whereas
production codec uses NumPy uint32 XOR. Neither replays floating-point updates.
Bound decompression to raw-length+1 and require exact length/end/no unused tail.

Structural fixture covers copy/compressed/raw modes, exact signed-zero/NaN/
infinity bits, wrong source, corrupted blob and bad offset rejection. This
fixture is separate from real-state all92 qualification. No quality early exit:
the underlying selected model still fails absolute quality18of18 labels.
