# METH-99: teacher-decision retention for specialized E1280 children

METH-98 shows that METH-96's 128-update children improve fresh-document BPB by 0.00129 over E128, but lower pooled donor prompt top-1 by 1.109 points, crossing the frozen one-point gate. Keep the METH-96 checkpoint as the starting point and test a separately frozen corrective continuation. The parent router, child router, A factors and BF16 donor remain fixed. Only child B factors update.

Use the same source-bound H0 raw and METH-43 chat training pools as METH-96, with NumPy seed 99099 for 64 updates and one raw plus one chat draw per update. Each loss is 0.25 times next-token CE plus teacher KL (weight 4 raw, 8 chat), plus a 1.0-weight teacher top-1 margin hinge. The hinge applies when the frozen BF16+E128 teacher's top-two logit gap is at least 0.2, and asks for a 0.2 student gap against its strongest competitor. Chat CE and margin cover assistant targets; KL covers all chat positions. AdamW child B only, learning rate 3e-5, zero weight decay, global clip 1.0. Save the exact draws and checkpoint. Stop on nonfinite values, >15 minutes, >10.5 GiB GPU peak allocation, or >20 GiB RSS. Local RTX 3060 only; no T4.

The distinctness gate is now functional in weight space: at least 640 child slots in every layer must have maximum B-coordinate difference >0.001 from child zero of their parent. This threshold is supported by METH-96's observed range (1,061–1,152 such slots), but quality is judged on a new, source-disjoint 24-document METH-100 manifest that excludes METH-97. The frozen development gates remain METH-96's: pooled BPB E1280−E128 ≤+0.01; each category ≤+0.02; pooled donor prompt top-1 E1280−E128 ≥−0.01; each category ≥−0.02. A pass permits external automatic and blind-semantic audits, not native promotion. CPU LUT and full `engine.c` rate still require independent evidence.
