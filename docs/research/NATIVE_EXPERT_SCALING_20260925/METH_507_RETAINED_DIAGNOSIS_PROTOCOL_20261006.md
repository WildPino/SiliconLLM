k includes the first different choice at step k as the LAST comparable state.
If generated trajectories are equal, compare every step. Incompatible stopping
with an otherwise identical prefix is a format/logic fault, not a usable sample.

Check argmax using lowest original vocabulary ID for ties. For donor winner d,
candidate winner c at the first differing step, convert stored F32 values to

```
m = Ld[d]-Ld[c] >= 0
p = (Lc[c]-Ld[c])-(Lc[d]-Ld[d]) >= m
```

runner-up margin and maximum tie counts. A small margin or state norm alone
does not attribute causality to a projection or quantizer.
