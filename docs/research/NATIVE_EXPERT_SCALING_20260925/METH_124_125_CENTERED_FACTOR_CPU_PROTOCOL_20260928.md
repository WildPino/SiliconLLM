# METH-124–125: native CPU parity and varied access for the quality-valid centered bank

METH-121–123 passed its frozen external quality gate. METH-104 timed only the unchanged parent/child routing bank; it contains no effective centered A/B factors. Measure those factors before pursuing a compact LUT code or full `engine.c` integration.

METH-124 exports the exact METH-56 parent router, METH-107 child projection and keys, and METH-119 centered child A/B factors as BF16 forward values, into a versioned native bank. Bind the BF16 donor, parent and child checkpoint SHA-256, METH-121 source manifest and selected prompt IDs. Check every exported tensor byte on readback. Capture actual BF16 pre-MLP hidden states from the centered model for first and last positions of one held-out prompt per layer, plus two seeded synthetic BF16 vectors per layer. For all 96 fixtures export PyTorch parent IDs, child IDs, BF16 gates and BF16 residual. A native C checker must match parent/child routes and gates (≤1e-5 absolute) and residual (≤0.03 absolute), and a one-byte residual mutation must fail. These are component tolerances and do not substitute for full-model logit parity.

METH-125 captures 256 selected actual prompt positions across the 24 METH-121 prompts, using the same 11/10 position allocation as METH-77. Bind every vector and source hash. The native checker must count selected distinct children per layer, addressed router bytes and selected A/B bytes. Run five single-thread repetitions in source order for routing and selected-factor residual separately, and report per-repetition timing, medians, bank bytes, RSS and checksums. Require route+residual median sum ≤4 ms/token-equivalent and ≤2× a matched E128 parent-bank control on the same positions. This is a component feasibility gate, not a 50 accepted-token/s claim. State whether the varied finite set actually touches enough distinct factor rows to pressure cache; do not call it cold DRAM.

Use local RTX 3060 for export/capture with ≤15 minutes, 10.5 GiB allocated GPU memory and 20 GiB RSS per run. Native runs ≤2 minutes per arm. No T4. The bank is BF16 factors plus FP32 routing, not a compact LUT encoding; a later LUT conversion must preserve quality and be timed separately. The donor core, attention, tokenizer, KV cache, logits and sampling are absent here.
