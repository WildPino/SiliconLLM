# METH-106–108: long-response teacher retention for distinct E1280

The METH-105 blind semantic gate fails because one E1280 answer gives no supported requested detail. The existing METH-43 teacher chat continuations used by METH-96/99 stop at 64 generated tokens, while 12/24 E128 external responses in METH-103 continue beyond 64 tokens. Test the source-disjoint training hypothesis that E1280 needs supervision on complete longer teacher answers. This is a new training rule, not reinterpretation of the viewed METH-102 responses.

METH-106 deterministically generates up to 128 greedy tokens for all 256 pinned METH-43 training prompts with the frozen BF16+METH-56 E128 teacher. Save prompt/source hashes, continuation IDs/text, EOS status and length. No METH-97/100/102 development or external prompt may enter this teacher corpus. RTX 3060 only; ≤10.5 GiB GPU allocation, ≤20 GiB RSS, ≤15 minutes. No T4.

METH-107 starts from METH-99's separately learned E1280 children. Freeze BF16 dense weights, parent/child routers, A factors and the E128 teacher. Update only child B factors for 256 steps, visiting every METH-106 chat row exactly once in a seeded permutation (seed 107107), paired with one source-disjoint H0 raw training draw per step. Use 0.25 CE + teacher KL (raw weight 4, chat weight 8) plus a teacher top-1 hinge of weight 1 on positions with teacher margin ≥0.2; chat CE/hinge cover assistant targets and KL all positions. AdamW learning rate 1e-5, no weight decay, clip 1.0. Stop on nonfinite values or the same 15-minute/10.5-GiB/20-GiB limits. Require at least 640 child slots per layer with a B-coordinate difference >0.001 from sibling zero. This update should learn teacher behavior through its full continuation, especially EOS/detail after position 64, while preserving distinct children; the mechanism remains a hypothesis until fresh quality measurement.

METH-108 freezes 24 new source-disjoint code/prose/technical documents and prompts before scoring. Development gates remain pooled E1280−E128 BPB ≤+0.01, each category ≤+0.02, pooled donor prompt top-1 difference ≥−0.01 and each category ≥−0.02, plus E1280 EOS count no more than two below E128 for 128-token greedy generation. Passing development permits another independent automatic and arm-blind semantic audit; it does not override METH-105's failed gate or establish native/LUT throughput.
