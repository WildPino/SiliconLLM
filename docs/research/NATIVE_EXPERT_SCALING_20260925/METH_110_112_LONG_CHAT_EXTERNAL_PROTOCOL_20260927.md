# METH-110–112: independent long-chat E1280 audit

METH-109 passes every frozen development gate on the METH-108 set. Freeze a new 24-item external manifest before scoring the METH-107 checkpoint. The checkpoint, training procedure and the automatic and semantic gates below are fixed. A pass does not imply native engine performance or establish 10B/100B scaling.

METH-110 selects eight code, eight prose and eight general technical sources with a fixed seed from the same pinned Git source pool used by prior audits, PG19 test/validation, and a new local Europarl English corpus. Exclude source IDs and overlapping text fragments from all prior calibration, development and external manifests through METH-108. Europarl is divided into disjoint 1-MiB byte buckets for candidate selection. These are distinct windows of one corpus, not independently curated documents; report this limitation. Do not use Simple English Wikipedia prose from METH-108 or any METH-102 prompt. Record source and token hashes before running inference.

METH-111 compares intact BF16 donor, BF16+METH-56 E128 and BF16+METH-107 E1280 on identical document and prompt IDs. Require E1280−E128 pooled BPB ≤+0.01 and each category ≤+0.02. Require donor prompt top-1 agreement difference ≥−0.01 pooled and ≥−0.02 per category. For 128-token greedy continuations, require E1280 EOS count at least E128 minus two, and repeated 8-gram three times and early non-EOS counts no greater than E128 plus one pooled or per category. On all 1,838 PIQA items, require E1280−E128 accuracy ≥−0.02 and paired bootstrap lower fifth percentile ≥−0.05. PIQA is reused from earlier audits and is a regression check, not a new independent task sample. Stop at the first failed automatic stage. RTX 3060 only, ≤10.5 GiB allocated GPU memory, ≤20 GiB RSS, ≤30 minutes.

If all automatic gates pass, METH-112 exposes only each 384-character excerpt and anonymous E128/E1280 continuations to an arm-blind semantic review. Commit the verdict before revealing the arm map. Count unsupported claims, severe unsupported claims and answers missing any supported requested specific detail. E1280 must have no more than E128 in each category. A single failed semantic gate rejects promotion regardless of automatic metrics. One reviewer and short excerpts limit the conclusion; record that limitation. Do not use the viewed verdict to retune this checkpoint and re-test on the same external set.
