# METH-193/194: Q8 core nearly matches loss but fails frozen ranking gates

The [protocol](METH_193_194_Q8_CORE_PROTOCOL_20260930.md),
[exporter](../../../benchmarks/donor_adaptation/s1/meth193_export_group64_q8_core.py)
and [four-arm scorer](../../../benchmarks/native_expert_scaling/meth194_q8_core_e1280_development.py)
were committed at `741f200` before execution. METH-193 stores one
signed symmetric int8 code per FFN weight with one FP16 scale per 64
inputs, reusing the exact METH-85 R8 tied head, BF16 attention and
FP32 controls. All 363 stored tensors and 72 reconstructed BF16 FFNs
matched byte for byte after reload. Maximum FFN weight relative L2
error is 0.7114%, down from Q6's 2.838%.

The local artifact at
`results/native_expert_scaling/meth193_qwen05b_instruct_group64_q8_core.safetensors`
is 548,741,304 physical bytes, SHA-256
`ab38c6bf591b59b993a273b112f0e3bdc889dbde35d576f62933f2843c4aa396`.
The [export ledger](meth193_group64_q8_core_export.json), SHA-256
`8223fcf4cb53fbd9c63665200d337bca436c49c5472f01c6cd765401f6c54c56`,
prices its ideal active core+router+selected-factor total at
**559,981,568 bytes/token**, 18,432 below the 560 MB allotment.
This excludes file header bytes and is neither a cache-traffic
measurement nor a measured native decoding rate.

METH-194 reproduced all METH-187 BF16 donor and centered-E1280
per-source document NLLs exactly, plus all BF16+E1280 donor-top-1
prompt counts. It then scored the Q8 core with the same E1280 bank on
the **already viewed** 24 METH-121 sources.

| Measure | BF16+E1280 | Q8+E1280 | Difference |
|---|---:|---:|---:|
| Pooled BPB | 1.184887 | 1.184919 | +0.000031 |
| Donor prompt top-1, 4,494 positions | 94.504% | 93.391% | −1.113 points |
| Code prompt top-1, 1,615 positions | 92.817% | 90.588% | −2.229 points |

Both pooled/category BPB gates pass. The frozen pooled top-1 gate
allows at most one point loss and the category gate at most two;
**both fail**. Prose gains one match relative to BF16+E1280;
technical loses 15/1,619 matches, inside its category allowance.
The [raw result](meth194_q8_core_e1280_development_result.json),
SHA-256 `9063af7040e063070a3f590e5be19001ffb48f8b007a2375db8dd17aa656ec1b`,
contains every source/category row and all four arms. Export took
76.406 s (92.1 MB peak GPU allocation), scoring 161.703 s
(4.270 GB peak GPU allocation) on the local RTX 3060. No T4 or
fresh source was used.

This Q8 candidate is **not promoted** to fresh quality or native
rate. The narrow miss warrants one format-equivalent, deterministic
weight-MSE scale refinement, fixed before examining its prompt
results. Even if that passes development, the 18,432-byte ideal
margin cannot be assumed to cover router growth as expert count n
increases by tenfold, let alone actual memory traffic. Native LUT
scaling and 10B/100B quality remain independent open gates.
