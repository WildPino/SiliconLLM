# METH-159: offline route-support preflight for independent tenfold training

Run only after all 40 METH-158 teacher shards have been verified and merged against the frozen 2,560-chat/2,560-raw manifest. Bind the exact METH-158 manifest, merged teacher file, pinned METH-126 shared-A bank, METH-56 parent, METH-107 child, BF16 donor and fixed METH-149 75-tuple table by SHA-256. Do not change template, table, hash constants or source selection after seeing traffic. This is an **untrained offline** screen to decide whether the expanded data provide more support per content specialist; it is not an external quality test.

For each of the 2,560 deterministic update pairs, forward the frozen centered E1280 teacher on the 127-token raw input and the prompt-plus-new-greedy-continuation chat input (excluding the last target ID), recover all 24 layers' four source-child IDs, and apply the exact METH-150 shared-structure/nine-way content hash. Set prior token zero and local position zero at the start of each input. Record full all-token, structural and content slot histograms, parent totals, source-row and continuation hashes, runtime and memory. Check exactly four selected grandchildren per token/layer and exact grandchild-to-source-child identity. Include the structural slot's traffic in total CPU work.

Before inference, freeze these gates on each layer: at least **10,000** of 11,520 content rows selected; median selections per active content row **>=50**; at most **50%** of content rows with fewer than 32 selections; the METH-150 global content maximum-load ratio `9 × max(content grandchild selections) / max(content source-parent selections)` **<=1.25**; and worst content-grandchild share **<=25%** for every parent with at least 250 content selections. The global ratio is not a per-parent balance guarantee; the hot-parent share is reported separately. Report the 10th/50th/90th active-row selection percentiles and all-token skew regardless of pass/fail. The thresholds deliberately improve upon METH-157's 8,673 minimum coverage, 7–13 median and 76.5–84.6% under-32 share on 256 updates, without using any held-out quality corpus.

Only a full preflight pass licenses freezing the matched long-budget E1280 control versus METH-155-style E12800 base/residual training protocol on these same 2,560 pairs, including both arms' resource and quality gates. The control must receive the same longer objective/budget. Reserve PG19 shard 9 for a later source/fragment-disjoint external quality audit, excluding METH-143/150/153/156 and the new training source rows. No T4; use the local RTX 3060, with a 60-minute preflight cap, 10.5 GiB allocated GPU memory and 40 GiB RSS. A route-support pass alone does not prove useful experts or native accepted-token speed.
