# METH-88/89: adapt learned experts to the stored grouped-R8 core

## Question and frozen rule

METH-86's stored core passes likelihood but misses prompt agreement. Test whether a short, source-bound distillation of the **existing distinct E128 experts** can absorb the fixed core's quantization error without increasing per-token addressed bytes. The BF16 donor plus the frozen METH-56 update-512 E128 bank is the teacher. The student uses the exact METH-85 stored grouped-R8 core and begins with the same E128 bank. The student core, product-key router and A factors are frozen; only the B output factors are trained. This preserves 128 separately learned expert identities and the bounded product-key candidate count. It is a new adaptation, not a claim that copied zero-output experts become new capacity.

Use 64 updates, each with one 128-token raw example from the pinned H0 training IDs and one METH-43 assistant-chat example, sampled by NumPy seed 88088. Train against the teacher's full logits using mean KL on raw tokens and assistant target positions for chat, plus 0.1 times a teacher top-1 margin hinge on positions where the teacher top-two logit margin is at least 0.2. The target hinge margin is 0.2. Use AdamW on B only, learning rate 1e-4, zero weight decay, global gradient clip 1.0. Train in BF16 model forward with FP32 objective, no core or router updates. Bind all source and checkpoint hashes, save the trained B/router/A state and exact training draw IDs. Stop on nonfinite gradients, time >15 minutes, peak GPU allocation >10.5 GiB, or process RSS >20 GiB. Use only the local RTX 3060; no T4.

METH-89 freezes 24 new source-disjoint documents and chat prompts before scoring. The test compares intact BF16 donor, BF16+original E128 teacher, grouped core with experts disabled, grouped core+original E128, and grouped core+adapted E128 on the same IDs. Promotion gates for the adapted arm: pooled BPB delta versus donor ≤+0.02 and each category ≤+0.04; pooled donor prompt top-1 ≥95% and each category ≥90%; pooled top-1 no more than one point below BF16+original E128; pooled BPB at least 0.001 better than the grouped core with experts disabled. All must pass. Passing development would permit a separate external generation, task and blind-semantic audit; it would not establish native rate, 10× expert scaling, or final quality.

METH-87's viewed prompts motivated this rule but are excluded from METH-89 selection. The exact METH-85 core format and byte ledger remain fixed at 557,106,176 ideal addressed bytes/token; a modified B bank changes values, not tensor shapes or selected-expert count. The training rule does not add a dense correction path.
