# METH-149: nonrecurrent content routes balance; 75 recurring contexts concentrate

**Decision: diagnostic evidence for a shared structural route, not promotion of METH-145.** Before replay, a source-only table froze all chat causal tuples `(current token, previous token, local position)` appearing in at least 32 of the 256 bound examples. It contains **75 tuples**, accounting for 16,629 of 54,095 chat input positions (30.7%). On the final rejected METH-145 bank, every layer reaches 100% worst hot-parent share in these recurrent positions. The other 37,466 chat positions have worst shares of only **14.49–18.46%** across layers; raw windows remain at 14.53–17.73%. The class split exactly reconstructs METH-147's already committed per-layer histograms.

The [protocol](METH_149_RECURRENT_CONTEXT_ROUTE_PROTOCOL_20260928.md) was committed at `6584d68`. The [table generator](../../../benchmarks/native_expert_scaling/meth149_recurrent_context_table.py) and [table](meth149_recurrent_context_table.json), SHA-256 `93b6ca77ece874889e83ae368b9f63d78bef8e90a9fbda37cb9e1a871cb0503e`, were committed at `9f79607` **before route inference**. The [replay](../../../benchmarks/native_expert_scaling/meth149_recurrent_context_route.py) was committed at `7ea3ff8`; the [result](meth149_recurrent_context_route_result.json) has SHA-256 `cf8087f1677bf9c60076e055f35ac95cdb2e7f426ab5dce3d54ad441ed2e28e2`, and its exact [segment counts](meth149_recurrent_segment_counts.npz) have SHA-256 `c1aea4b3a38c17a6a97ecf5b0a18287d13a7d67b453103472a0d7a21886a6f5d`. They match the METH-147 merged counts exactly and replay the same 256 raw/chat draws at final weights.

The last column derives from the saved histogram as `10 * maximum_grandchild_count / maximum_parent_aggregated_count` for each layer and takes the worst. It is a **within-candidate** dispersion measure, not the METH-145 comparison to the independently trained E1280 control. All raw and other-chat layers fall below 1.25× by this diagnostic measure. Recurrent positions explain the conditional hotspots, but they still consume 16,629 real input positions and cannot be dropped from CPU cost or model loss. The threshold 32 was chosen after observing this training mixture, so the result is exploratory and needs an unchanged rule on newly selected sources.

The existing 4.40 GB bank remains rejected because the frozen METH-145 all-token gate failed. A new method can reserve a shared B path for recurrent structural contexts and distribute other positions over the remaining specialists, provided it freezes the table, C/Python parity, native CPU cost, matched training-load rules and a source-disjoint quality audit **before** testing. This result supports trying that mechanism; it does not show that a newly trained bank preserves or improves quality. The local RTX 3060 replay took 121.282 seconds, 15.627 GB final process RSS and 1.243 GB peak allocated GPU memory. No T4 was used.
