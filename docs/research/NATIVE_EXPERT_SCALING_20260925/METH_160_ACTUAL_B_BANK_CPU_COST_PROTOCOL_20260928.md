# METH-160: actual learned B-bank CPU selected-path cost at tenfold E

**Question.** METH-151 measures the shared/content route at E12,800 without reading expert B factors. METH-125/130 measure varied-token E1,280 factor arithmetic, but E12,800's larger actual learned bank may increase page and DRAM cost even with four active experts. Measure that cost before assuming an affordable native LUT path. This is an inference-component feasibility test, not a quality or full `engine.c` test.

**Bound inputs.** Use the METH-126 exact shared-A/router bank SHA-256 `1d9071456a644344d46203ad7ded8fe2c4d01ca0580b5e41718366783408aff1`, METH-125 E1,280 BF16 hidden vectors SHA-256 `f7af00b4b4ce417664848950770f63b78520ca3c983748a692640704c203b699`, METH-151 structural table SHA-256 `926362655bcc71bf7bd1ceee944e56ba8f35ef124c8f60b6e0052d6525ddfc27`, hit contexts SHA-256 `c211bde3459b3a1df27250ee0e785cde412cba07fb763aeb519281588f54a629`, miss contexts SHA-256 `ecce0701d71201f9a48495adbc9814632c9f5b0929675a30daf2ffc92ac8682e`, METH-136 256-update continued E1,280 B bank SHA-256 `d5d9e6b3753ab55ecbb20a8f60d1ba11a6d9bdd41f66bb34909207b9a29ba299`, and METH-155 learned-base E12,800 B bank SHA-256 `c335d425c97fac5ec7284eea97ce3f3dc9462264ec79e7f46ce8598465d3e01d`. Verify hashes before timing. METH-156 rejected the E12,800 bank on fresh pooled BPB; its use here is solely to measure physical layout/access cost for the current architecture.

**Method.** Memory-map both B files read-only with their native headers and exact lengths. Load the fixed shared-A/router bank and 256 actual BF16 E1,280 hidden vectors from METH-125. Cross those vectors with both METH-151 context fixtures as a deliberately constructed component workload; the contexts were not captured from the same model positions. For each token/layer, route once through the fixed E1,280 parent/child hierarchy, preserve four BF16 gates, then map each selected source child either to its E1,280 B row or to its METH-150 shared/content grandchild. Assert every grandchild/10 equals its source child, the shared slot is exactly local zero, every route/gate and residual is finite, and selected B bytes per token are identical. Shared A is indexed by the original 128-parent ID for both arms. Confirm the control path against the existing METH-124 residual arithmetic on selected states. Report unique B rows touched, unique B bytes, bank size, process RSS and page-fault deltas.

Run five paired single-thread repetitions per fixture, alternating E1,280-first and E12,800-first. Time route plus B-factor arithmetic on all 256 tokens × 24 layers, as well as route-only, and report each repetition plus medians. Freeze **both** component gates before timing: E12,800 route-plus-factor median <=5.0 ms/token-equivalent and <=2.0× the matched E1,280 median, separately for structural-hit and content-miss fixtures. Stop at five minutes elapsed or 10 GiB process RSS. Run only after the active METH-158/159 GPU work finishes, so its CPU activity does not perturb this timing. Use local Ryzen 5 3600X, one thread, `clang -O3 -mavx2 -mfma -std=c11 -Wall -Wextra -lpsapi`.

**Limits.** Mapped pages and repeated fixtures do not prove cold physical DRAM latency. Crossed states/contexts and the quality-rejected E12,800 weights do not prove full-model parity, useful learned capacity, compact pair-LUT quality or speed, >=50 accepted tok/s, or behavior at 10B/100B. The result will determine whether this selected BF16 path is affordable enough to remain a reference for later compact LUT integration; a failure requires a different memory representation or access strategy before promoting the E12,800 rung.
