# METH-144: model-integrated token-hash clone parity and native CPU route cost

METH-143 passes new-source traffic balance with the fixed METH-142 hash, but it assigns grandchildren offline after the original E1280 model run. This experiment puts the exact hash inside the 24-layer expert forward path with cloned BF16 B rows and measures its native C routing cost. It does not train the grandchildren or establish semantic quality, compact LUT arithmetic or end-to-end accepted-token throughput.

Bind the METH-143 result SHA-256 `d13aeb90b8211fc5be6a1289f0209d1f846691b9be7f4621a06e0845538d749f`, METH-142 hash seed `142142`, its five unsigned 64-bit constants and golden tuple `(123,45,67,89,3) -> 899`. Bind the original METH-126 exact BF16 bank SHA-256 `1d9071456a644344d46203ad7ded8fe2c4d01ca0580b5e41718366783408aff1`, METH-107 child checkpoint SHA-256 `15a14b8476936e83cf91a479b05f8d8e83f4ffd094186f3d4dfededdb138d520`, METH-121 parity manifest SHA-256 `7f35f2253850f3a19e0bf517d2e088d2d08c88c0bc68cc09413781ddac6f9366`, and METH-143 manifest SHA-256 `e6c4fb6a92929eb29332c55a0887adb6627c9528f80b21c09f7759139070ccff`. For native cost bind METH-125's 256 actual E1280 vectors SHA-256 `f7af00b4b4ce417664848950770f63b78520ca3c983748a692640704c203b699`.

## Model gate

Use the donor and frozen E1280 parent/child routes, four gates and shared A unchanged. Build an E12800 CPU B bank by cloning each exact BF16 E1280 row ten times. Supply current token, previous token and zero-based position within each tested sequence to the expert forward path; fail if context is missing or has the wrong shape. The selected grandchild ID must come from the frozen unsigned hash inside the expert's `forward`, before B gathering. Check `grandchild // 10 == original child` for every selection. Check the initial cloned B bytes before routing. Run eight bound METH-121 prompts and eight METH-143 fresh prompts, each as a single sequence with previous token zero at its start, comparing the E1280 teacher and hash-routed clone. Require exact BF16 equality of **every logit**, original child IDs, and gates; require nontrivial grandchild selection. The context setter must also work for repeated forward calls and the gradient-checkpointing recomputation used by later B-only training.

## Native gate

Implement the identical unsigned 64-bit arithmetic, modulo ten and golden vector in C. On all METH-125 actual states, retain the original E1280 parent/child selection and gates, apply the hash to four children using a frozen deterministic token-context fixture, check C/Python hash agreement for every tuple, and require `grandchild / 10 == child`. The fixture supplies token IDs/previous IDs/window-local positions; it is an instrumentation input for route cost, not a claim that those METH-125 hidden states arose from those token IDs. Make five paired single-thread route-only timing repetitions with alternating order. Require hash E12800 median <=3.0 ms/token-equivalent over 24 layers and <=2.0× the matched E1280 route median. Report all repetitions, coverage, checksum and nominal addressed bytes. This is warm component timing, not cold DRAM or full-model throughput. Check a corrupted fixture header fails.

Stop model execution after 15 minutes, 10.5 GiB GPU allocation, 20 GiB process RSS or 100 MB new output. Use only the local RTX 3060. Stop native execution after two minutes and 3 GiB RSS. No T4. A joint pass licenses a separately frozen matched sparse B-only training run and source-disjoint semantic quality; a parity or cost failure stops that rung.
