# METH-104: native CPU cost of the learned E1280 hierarchical router

The METH-99 checkpoint supplies a fixed parent product-key router, rank-32 child projection and ten keys per parent, with exactly four selected children per token/layer. Export these FP32 router tensors byte-for-byte to a versioned native bank. Capture BF16 pre-MLP hidden states from a source-bound METH-102 prompt under the frozen BF16+E1280 model. Export parent IDs, child IDs and gate values from the Python model for first/last actual positions and two seeded synthetic vectors per layer (96 fixtures). Require native parent and child IDs to match on every fixture and gate error ≤1e-5. Include a one-byte negative-control fixture mutation that makes the checker fail.

On the same 24-layer hidden vectors and the same single-thread host, measure five repetitions of 1,024 token-equivalent passes for parent-only E128 routing and hierarchical E1280 routing. Report median and ranges, router bank bytes and RSS. The fixed gate is hierarchical route median ≤3 ms/token and ≤2× parent route median. This isolates routing only. It does not time factor DRAM access, LUT factor arithmetic, tokenizer, attention, logits or accepted-token throughput. Passing it does not establish that the full CPU LUT or `engine.c` model scales, especially at 100B.
