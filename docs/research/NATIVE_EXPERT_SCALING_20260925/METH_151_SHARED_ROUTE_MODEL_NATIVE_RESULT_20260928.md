# METH-151: integrated shared-route clone parity and native CPU cost pass

**Decision: joint model/native routing component pass; learned quality pending.** The fixed 75-tuple structural lookup and nine-way content hash select a grandchild **inside** every one of the 24 expert forwards before B gathering. With ten exact BF16 B clones per source child, all logits, parent routes, scores, derived gates and source-child IDs match the E1280 teacher exactly on 17 sequences: eight bound prompts, eight prompts from the METH-150 newly selected sources and one recurrent training chat prefix. Both structural and content routes are exercised (60,672 and 237,600 selections summed over these full-model checks). Missing token context is rejected, and non-reentrant checkpoint recomputation reaches the sparse B-gradient collector in every layer. This verifies initialization and routing plumbing, not useful training.
