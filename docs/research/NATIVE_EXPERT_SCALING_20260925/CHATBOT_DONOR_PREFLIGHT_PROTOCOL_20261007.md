## Operations and decisions

1. Hash/read full config/tokenizer_config/tokenizer JSON and optional generation
   config. Tokenizer JSON is hashed, not executed or tokenized. No implicit
   tokenizer/default template/model download. Record original config and
   generation EOS IDs without substituting a chosen greedy policy.
2. Read ONLY safetensors headers, validate dtype/shape/contiguous offsets/file
   lengths, and exact index name-to-shard agreement. Never hash/read tensor
   values. Header hashes are hashes of their exact extents, not whole-weight
   file SHA. Sum named parameter elements and dtype bytes; no weight uniqueness/
   intelligence claim. Layers at or beyond base depth are reported separately
   without assuming those names establish the complete MTP boundary.
3. Classify Qwen2 SiLU as causal dense SwiGLU/GQA, DeepSeek-v3 SiLU as causal
   MoE SwiGLU/MLA. This identifies family prerequisites; neither is an implemented
   compact converter. Other families explicitly return unimplemented adapter.
   Check source-specific biases, RoPE, shared expert, router/normalizer and head.
4. Optionally read ONLY bounded producer GGUF v2/v3 metadata. Extract template,
   architecture, BOS/EOS and finetune tags. Hash exact prefix through metadata;
   do not read tensor descriptors/payload or presume HF/GGUF equivalence.
   Producer-only template is a candidate requiring explicit ID/rendering parity,
   not an automatically qualified replacement for missing HF chat metadata.
5. Record missing full-pipeline gates and ALWAYS report
   `SOURCE_CONTRACT_INSPECTED_PIPELINE_NOT_QUALIFIED`. No auto execution of old
   scripts or rendering of untrusted source templates. First-family native
   evidence/quality/rate remain attached to their original artifacts/scopes.
