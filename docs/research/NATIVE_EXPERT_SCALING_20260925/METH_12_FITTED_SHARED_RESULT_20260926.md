# METH-12 result: fitted linear shared residual does not compose end to end

**Decision:** reject this rank-256 shared residual plus E37 top-16 geometry
before joint training or native export. The [protocol](METH_12_FITTED_SHARED_PROTOCOL_20260926.md)
was written before scoring. The [machine result](meth12_fitted_shared_pilot.json)
and [runner](../../../benchmarks/donor_adaptation/s1/meth12_fitted_shared.py)
preserve the bound inputs and per-layer validation. This failure does not
rule out a jointly trained nonlinear core or other donor families.

## Local fit and paired end-to-end quality

Rank-256 fit lowered local residual SSE on the four withheld calibration
windows in **21/28 layers** and worsened it in seven. Summed over all
layers, fitted/sparse-only SSE was **0.947689**, a 5.23% reduction.
The per-layer ratio ranged from **0.757059** to **1.171752**. These
observations are not end-to-end quality; downstream inputs change when
all 28 fitted modules are installed together.

| Arm, identical first two 512-token heldout windows | BPB |
|---|---:|
| Intact donor | 0.960190 |
| E37 top-16/256 original groups plus fitted rank-256 shared path, all 28 layers | 1.904063 |
| Paired delta | **+0.943873** |

The delta exceeds the frozen +0.20 step-zero stop by **0.743873 BPB**.
The pilot was previously used by H1 and METH-11, so no final
generalization claim follows. No generation, task or native C test was
run after this gross failure. METH-11 and METH-12 change multiple geometry
details; their deltas should not be subtracted to estimate the causal
benefit of fitting the shared path.

## Cost and next decision

The conditional FFN would address **94,273,536 weights/token** across
28 layers: 72,253,440 from top-16 donor groups plus 22,020,096 in
rank-256 shared factors, versus 1,156,055,040 for the dense donor FFN.
An exhaustive E256 router adds 11,010,048 score weights/token. These
are shape counts, not measured bytes or C performance. The current
Qwen donor engine still reads its tied fp32 head (~933.5 MB/token),
already too costly for a 50 tok/s byte budget at 40 GB/s.

Local linear reconstruction is not a reliable proxy for preserving
whole-model quality under simultaneous layer replacement. The next
transfer candidate needs a **jointly trained** compact core and router,
or a distinct pretrained sparse donor whose useful expert structure can
be retained without this post-hoc conversion loss. Specify training
exposure, optimizer RAM, exact source-to-target mapping and a low-bit
head/native export path before spending GPU time. At larger E, test
router recall and quality with distinct trained experts, not just fixed
top-k arithmetic or a full-scan shortlist.
