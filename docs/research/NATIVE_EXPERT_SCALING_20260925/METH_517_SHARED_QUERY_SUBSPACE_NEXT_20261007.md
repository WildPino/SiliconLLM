u=B^T w,v=B^T q, e_w=w-Bu,e_q=q-Bv. Then exactly

    w^T q = u^T v + e_w^T e_q + u^T(I-G)v.

For a verified rho>=||I-G||2, rho<1,

    ||e_w||2^2 <= ||w||2^2 - (1-rho)||u||2^2 = Rw,
