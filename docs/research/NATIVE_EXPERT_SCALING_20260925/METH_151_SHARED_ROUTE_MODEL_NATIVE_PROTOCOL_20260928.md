# METH-151: integrated shared-route clone parity and native CPU cost

METH-150 passes the newly selected source-held-out **content** route screen offline, but its shared/context lookup has not run inside the 24-layer model or native C. This experiment decides whether the fixed rule is function-preserving with cloned B and cheap enough as a CPU routing component. It cannot show learned expert usefulness, quality-valid factor quantization, cold factor traffic or end-to-end accepted-token rate.

Bind METH-150 result SHA-256 `f6298315e584afb156681cfc40c45de5608f45a896f343fdc8edb86d95ae359b`, its precommitted new-source manifest SHA-256 `6e911e65529be53dba65fbe382229f0f43e510eb76ab83f4404d4be0368ff5d9`, METH-149 75-tuple table SHA-256 `93b6ca77ece874889e83ae368b9f63d78bef8e90a9fbda37cb9e1a871cb0503e`, METH-126 exact BF16 bank, METH-107 checkpoint, donor/parent and METH-125 actual vectors by their earlier hashes. Retain the METH-142 unsigned mix and METH-150 rule exactly. Golden content `(123,45,67,89,3)->899` and shared `(11,16948,7,89,3)->890` must match in Python and C.

Build 12,800 CPU B rows by ten exact BF16 clones per E1280 source child. With the shared choice **inside** every expert `forward` before B gathering, run eight bound METH-121 prompts, eight newly selected METH-150 prompts and one bound training chat prefix containing recurrent tuples. Set current, previous and sequence-local position for each forward; fail on missing/mismatched context. Require exact BF16 equality of every E1280 teacher versus shared-route-clone logit, parent route, parent score, derived gate and source child in every layer. Require every grandchild divided by ten to recover its source, structural choices to use local ID 0 and all other choices local 1–9, with both kinds exercised. Require complete BF16 clone-byte equality and one backward pass through non-reentrant checkpoint recomputation with sparse B collection. Test repeated forwards.

Export a versioned 75-tuple native table sidecar and deterministic 256-tuple context fixtures: one with only METH-150 newly selected document contexts that miss the table, another with recurrent tuples from the frozen table. Freeze and byte-verify these before timing. The METH-125 hidden states are actual E1280 states but are not paired with the fixture tokens; this measures routing arithmetic, not a model trace. C must reject corrupted table magic, match both golden vectors, preserve all 6,144 original child/gate routes and source recovery, and agree with Python on all 24,576 selected grandchildren per fixture. Make five paired single-thread E1280 versus shared E12800 route-only repetitions with alternating order for each fixture. In **both** hit and miss cells, require shared-route median <=3.0 ms/token-equivalent over 24 layers and <=2.0× the paired E1280 median. Report all repetitions, structural hits, coverage, checksum and addressed bytes. This warm component measurement includes table lookup and mix for misses, but neither B-factor DRAM access nor full `engine.c` inference.

Use the local RTX 3060 for model parity, stopping at 15 minutes, 10.5 GiB GPU allocation, 20 GiB RSS or 100 MB new output. Use the local CPU for native timing, stopping at two minutes, 3 GiB RSS or 100 MB new output. No T4. Only a joint pass licenses a separately frozen B-only matched training rung and then untouched quality.
