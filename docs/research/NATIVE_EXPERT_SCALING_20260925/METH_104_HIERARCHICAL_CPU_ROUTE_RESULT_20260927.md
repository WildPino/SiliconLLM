# METH-104: learned hierarchical E1280 CPU router passes component cost

**Decision.** On 96 source-bound fixtures, the native C router returns exactly the same four parent IDs, four child IDs and BF16-rounded gates as PyTorch. The single-thread Ryzen 5 3600X median for a 24-layer E1280 hierarchical route is 1.476525 ms/token-equivalent, 1.508× the same-bank E128 parent route median of 0.979333 ms. It passes the frozen ≤3 ms and ≤2× component gates. This is a route-only, hot-input result, not a CPU LUT factor or full-model throughput result.

The [protocol](METH_104_HIERARCHICAL_CPU_ROUTE_PROTOCOL_20260927.md) was committed at `ae138fe` before export. The [exporter](../../../benchmarks/native_expert_scaling/meth104_export_hierarchical_router.py) binds the METH-99 E1280 checkpoint, METH-56 E128 parent and METH-102 prompt, captures first/last actual BF16 pre-MLP states plus two fixed-seed vectors per layer, exports a versioned FP32 router bank and verifies every tensor byte on readback. The [export ledger](meth104_hierarchical_router_export_result.json) binds bank SHA-256 `c86c1cbb62fa683bbe254af8f8302c4299f39c35789db392e946a314e9a701e0` and fixture SHA-256 `24584cbf107ff9195bbe1459041660a381fd7c986d612d634c551156f7eabebc`. The bank is 12,337,188 bytes: 5,652,480 parent-router bytes, 2,752,512 child projection bytes and 3,932,160 child-key bytes, plus a 36-byte header.

The [C checker](../../../benchmarks/native_expert_scaling/meth104_hierarchical_cpu_route.c) was compiled with Clang `-O3 -std=c11 -Wall -Wextra` without diagnostics. The [native log](meth104_cpu_route_native_raw.log) records zero fixture failures and zero maximum gate difference. Altering the first expected child ID in a copy of the fixture makes the checker exit 1 with one fixture failure; the [negative-control log](meth104_cpu_route_negative.log) retains that result. Timing uses five repetitions of 1,024 token-equivalent passes. E128 parent range is 0.968192–1.034733 ms; E1280 hierarchical range is 1.457132–1.537979 ms. The C process RSS is 16,166,912 bytes with the router bank loaded. A preliminary run under concurrent GPU audit also passed but is not used for the official timing.

No child A/B factors are in this router bank or timed by this checker. The separate METH-76/77 CPU factor-access results apply to a different E1280 route and failed-quality checkpoint; they cannot substitute for measurement on METH-99. This router is FP32, not a LUT implementation. Cold varied-token factor traffic, compressed factor arithmetic, the whole `engine.c` path and ≥50 accepted tokens/s are all unmeasured for this candidate. The METH-105 semantic gate failure also prevents native promotion.
