# Preferenze del proprietario

- Non aggiungere firme, attribuzioni automatiche, nomi di assistenti, modelli o fornitori a commit, messaggi di commit, descrizioni, messaggi di lavoro o nomi di branch.
- Non aggiungere trailer di coautoria o diciture che attribuiscano il lavoro a strumenti di generazione.
- Per i nuovi branch usare nomi descrittivi del lavoro, per esempio `feature/local-chat`, senza prefissi che identifichino un assistente o un fornitore.
- Conservare l'identità Git configurata dal proprietario; non sostituirla con un'identità di servizio. Se manca, chiedere l'identità da utilizzare prima di creare commit.
- Questa preferenza riguarda l'attribuzione del lavoro: non richiede di eliminare nomi tecnici necessari di modelli, protocolli o dipendenze.
